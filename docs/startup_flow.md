# Dabba — Startup Flow

Dabba ships three entry points: FastAPI (`api.main:app`), Streamlit
(`app/streamlit_app.py`), and the training pipeline (`python -m dabba.pipeline`).
The root Dockerfile runs API + Streamlit together (`CMD sh -c "uvicorn … & streamlit …"`);
`docker-compose.yml` runs them as separate services plus Redis/MLflow.

## FastAPI startup (`uvicorn api.main:app`)

1. Import phase — `api/main.py` loads `dabba.config` (env: DB URL, Redis URL,
   model paths, LLM keys) and constructs lazy singletons:
   - SQLAlchemy engine/session factory (`dabba.database.session`)
   - Redis client (`dabba.cache.redis_client`) — optional, degrades gracefully
   - Recommender/ETA/rating model wrappers from `models/` artifacts
2. App assembly — FastAPI instance with CORS, rate limiter (`api/limiter.py`,
   Redis-backed), auth middleware (`api/auth.py`).
3. Router registration — `chat`, `recommend`, `eta`, `explain`, `restaurants`,
   `model_info` (each thin, delegating to `dabba.*` facades via `Depends()`).
4. Ready to serve — `/health`, `/docs` (OpenAPI), business endpoints.

## Streamlit startup (`streamlit run app/streamlit_app.py`)

1. `streamlit_app.py` imports the same `dabba.*` facades (model load at import).
2. Multipage router registers `app/pages/`: `page_discover`, `page_concierge`,
   `page_ops`, `page_model_performance`; theme from `app/assets/theme.css`.
3. Each page calls `show()` lazily; components from `app/components/`
   (e.g. `restaurant_card`); sanitization via `app/utils/sanitize.py`.

## Training pipeline (`python -m dabba.pipeline` / `make train`)

1. `dabba.data.loaders` + `cleaning` → processed datasets in `data/processed/`.
2. `dabba.features.*` → feature frames (delivery, restaurant, geo, traffic).
3. `dabba.models.model_selection` (with `optimizer` Optuna + `evaluation.metrics`)
   → best models written to `models/` (`best_rating_model.pkl`,
   `best_eta_model.pkl`, `best_collaborative_model.pt`, `restaurant_faiss.index`).
4. `dabba.evaluation.business_cost` + `reports/` artifacts generated;
   MLflow experiment logged (`mlflow.db`).

## Operational entry points

| Entry | Command |
|---|---|
| API | `uvicorn api.main:app --reload` (Makefile `make api`) |
| UI | `streamlit run app/streamlit_app.py` (Makefile `make app`) |
| Train | `python -m dabba.pipeline` (Makefile `make train`) |
| Seed DB | `python -m dabba.database.seed --full-import` (Makefile `make seed`) |
| Migrate | `alembic upgrade head` (Makefile `make migrate`) |
| Kaggle data | `python setup_kaggle.py` |

## What must exist at startup

- Env keys from `.env.example` (DATABASE_URL, REDIS_URL, model paths, LLM keys)
- Trained artifacts in `models/` (generated by `make train`)
- `data/processed/*.csv` (generated by the pipeline / seed)
- Alembic migrations applied (`make migrate`)
