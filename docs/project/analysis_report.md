## 6. Security / Quality Findings (flag-only)

- JWT auth + slowapi rate limiting in place; secrets via env (`.env.example`). No hardcoded credentials found.
- `data/dabba.db*` contained real restaurant data — untracked but preserved on disk.
- pandas 3.0.5 installed locally **violates the project's own pin** (`pandas>=2.0,<3.0`) → 3 pre-existing `test_cleaning.py` failures on this machine only (pandas 3.0 changed `str` dtype semantics). CI on a correctly provisioned env is unaffected.
