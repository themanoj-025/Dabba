# Contributing to Dabba

Thanks for your interest in Dabba! Bug reports, documentation, and pull requests are welcome.

## Getting started

1. Fork the repository and clone your fork.
2. Create a feature branch: `git checkout -b feature/amazing`.
3. Run `make setup` to install dependencies.

## Development workflow

- Add or update tests for every change.
- Run the test suite: `make test`.
- Run the linter: `make lint`.
- Auto-format code: `make format`.
- Verify the dashboard boots with `make run-app` and the API with `make run-api`.

## Commit conventions

Keep commits small and focused. Prefix messages with a type, e.g. `feat:`, `fix:`, `docs:`, `test:`.

## Opening a pull request

1. Push your branch and open a PR against `main`.
2. Describe what you changed and why.
3. Link any related issue.
